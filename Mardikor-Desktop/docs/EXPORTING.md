# PDF 与 EPUB 导出

在编辑器的「校验与导出 → PDF / EPUB」选择格式，直接调整版式、封面和目录等选项。已有预设会载入表单，同一格式有多份预设时可切换。没有预设时会显示默认值，直接预检或导出不会创建配置文件。修改选项后，保存、预检或导出会创建或更新 `publication.toml` 中对应格式的预设。作品信息的修改保存在 `mdk.toml`，正文样式来自 `settings.toml` 和所用预设的覆盖字段。独立 Markdown 的 PDF 配置保存在本机。

- 三种 MDK 模式均可使用流式或固定版式 PDF，以及可重排或固定版式 EPUB。输出以 `contents.toml` 中目录节点的顺序为准。分组进入导航，同一正文的不同节点可分别显示。
- PDF 可指定毫米纸张尺寸、四侧边距、封面与目录，流式版式可指定章节换页。出版器检查文字实际使用的字体是否嵌入。
- 在「排版与字体」可选工程字体或内置 Noto 无衬线、衬线、等宽字族。「打包字体文件」将允许分发的独立 OTF / TTF 复制到 `resources/font/` 并选为当前导出字体。独立 Markdown 会把字体放在文档旁的资源目录。工程文稿显示遇到缺失字体时会提示并使用内置 Noto Sans CJK SC。导出预检会报告缺失项，可在当前预设里改用内置回退字体。
- 工程设置和导出页都可以搜索本机系统字体。系统字体选择随工程或导出预设记录为应用扩展，工程只保存字体标识。PDF 和 EPUB 出版时从本机读取所选字形，并执行字体嵌入权限和字形覆盖检查。需要在其他设备复用字形时，可使用允许分发的包内字体。
- 点击「预览 PDF」可在独立窗口查看按当前配置生成的实际 PDF，包括分页、目录和页码。预览会先做严格预检，并在需要时保存当前配置。正式保存 PDF 请使用导出面板的「导出 PDF」。
- EPUB 可指定方向及封面。固定版式还可设置页面大小、双页和首项单页。EPUB 需要作品标题、BCP 47 语言标签和稳定的绝对 URI 标识。可重排版可使用阅读器字型，使用包内字体时须启用嵌入。
- 预检检查所选预设、正文、标题锚点、实际引用的图片和字体。另一份无效预设可独立保留。固定版式超出页面时会报告。执行导出前再次核对工程修订和目标路径，成功后发布完整文件。
- PDF 预检按实际纸张、边距和字体排版。如果表格或单元格内容放不下，会报告对应文稿和表格起始行，并阻止导出。可加宽纸张、缩小左右边距或拆分表格后重新预检。

预设示例见 [定稿书籍工程](examples/v2/book/publication.toml)。在工程设置中可打开该 TOML 文件。字段定义见 [MDK v2 规范](<MDK Format Specification v2.md>)。

出版器支持静态 PNG、JPEG 和被动 SVG。MDK v2 的原始 HTML、公式及未注册的语法按规范的基础 Markdown 显示。可重排 EPUB 的字号、字型和分页可由阅读器决定。通用字体不承诺跨平台分页一致。

在桌面端构建后，运行 `npm run test:mdk-v2` 验证实际导出。出版转换的当前实现限额为 1,000 个正文节点、8 MiB Markdown、单张位图 4,000 万像素、单次渲染 60 秒和输出 256 MiB。暂未实现的高级共享样式会在预检中报告。
