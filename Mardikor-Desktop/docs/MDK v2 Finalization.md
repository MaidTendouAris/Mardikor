# MDK v2 定稿说明

定稿日期：2026-11-16。核心格式版本为整数 `2`，标准设置能力为 `mdk.settings-full@1`。

[主规范](<MDK Format Specification v2.md>) 与 [设置目录](<MDK v2 Settings Reference.md>) 共同组成 v2 定稿。Mardikor 0.3.1 的桌面端和 CLI 已采用 v2。本文记录规范修订，功能范围见桌面端的[使用指南](USER_GUIDE.md)和[命令行指南](CLI.md)。

## 1. 最后一轮修正

依据 [Draft 4 复核记录](<test-report/MDK v2 Draft 4 复核记录.md>) 完成以下处理。两份原始检查报告及 [Draft 4 处理记录](<MDK v2 Review Resolution.md>) 的历史内容保留。

| 编号 | 定稿处理 | 位置 |
| --- | --- | --- |
| R1 | 节点遍历明确显示“后代正文节点的正文”，统一未编排正文的表述。 | 主规范 §6 |
| R2 | 对规范性设置文档统一使用“设置目录”，基础集合之外的能力仍可称补充能力。 | 主规范 §7、§10、§11、§13、§17 |
| R3 | R 统一定义为“阅读编排、导航及视图附加信息”；V 为屏幕预览。 | 主规范 §10.1、§11.1 |
| R4 | 奇数末项位于双页组的首项位置：LTR 左、RTL 右。首项单独显示时保持单页展示框宽度，在双页区域水平居中。设置目录与 EPUB 映射同步。 | 主规范 §7、§11.3；设置目录 §16 |
| R5 | PDF 只生成已开启的附加页，顺序为封面、目录、正文；两个开关均关闭时直接从正文开始。 | 主规范 §11.2 |

| R8 | 作品标识在核心校验阶段检查绝对 URI 通用语法；非法时报告 `mdk.core.invalid`／`error` 并定位字段，不能写入出版元数据。省略与非法分开处理，不以联网可达性校验标识。 | 主规范 §5.2、§17 |

| R10 | “不正常覆盖”改为“禁止正常覆盖”。 | 主规范 §14.2 |

| R12 | 修正漫画示例左右位置描述，并标记节点 ID。 | 主规范 §16.3 |
| R13 | 明确冲突来自自动锚点及去重后缀。 | 主规范 §17 |

| R16 | 未知持久数据普通保存时不得静默删除；未在已声明内容或已确认范围内的数据不得自动加入出版物。显式删除／筛选／出版选择仍有效。 | 主规范 §15、§17 |

R8 按工程元数据的核心字段处理，而非延迟到不同出版器自行判定；其语法明确引用 [RFC 3986 §4.3](https://www.rfc-editor.org/rfc/rfc3986#section-4.3) 的 `absolute-URI`，包含 scheme 且不含片段。MDK 明确排除 `C:/books/a` 等盘符路径，防止把盘符误识别为 scheme；其他未知 scheme 本身不构成错误，也不授权读取资源。

上一轮已明确的取舍保持不变：纯 ZIP 容器、无二字节前缀、整数排序键、Markdown 正文权威、模式共用内容模型，以及基础交付与出版依赖范围分离。没有新增一图一页限制、旧格式转换或自动资源清理功能。

## 2. 定稿同步与验证

主规范、设置目录、设置模板、示例说明及检查脚本均改为定稿标识。桌面文档入口、现行 v1 使用说明和安卓 README 同步规范状态，同时保留各自的实现范围。历史报告及历史验收记录保留当时的版本描述。

运行方式：在 `Mardikor-Desktop` 执行 `node scripts/check-v2-examples.mjs`。

验证通过：16 个规范片段与示例一致，其中 10 个 TOML 片段解析；179 个设置字段覆盖（174 个活动字段、5 个注释字体集字段）；四个示例工程的目录、5 个正文活动链接及锚点；四个 `.mdk` 包全部 23 个条目的解压字节，以及物理首两项的顺序、压缩方法和 UTF-8 标志。独立 ZIP 检查通过 CRC 和记录边界复核。最终结果记录在 `.test-artifacts/mdk-v2-examples/`；原始检查报告及复核记录的 SHA-256 与修改前一致。

主规范 §17 现有 53 条一致性用例，新增覆盖双页首项／末项、PDF 附加页开关、缺省元数据、非法作品标识、第三方目标选择及隐私边界。它们是实现应覆盖的要求列表，不表示本轮已实现并执行全部行为测试。

本轮不改应用读写或出版实现，也未执行 PDF／EPUB 实际排版。示例检查不替代不可信容器安全测试、完整设置渲染、字体嵌入及许可检查、未知数据往返或外部标准符合性验证。
