# 使用指南

本指南适用于使用 [MDK v2](<MDK Format Specification v2.md>) 的桌面端。旧版 MDK 请用对应版本的 Mardikor 打开。

- **Windows 右键新建**。安装版可在资源管理器的文件夹空白处或桌面右键，选择「新建 → Markdown 文档」或「新建 → MDK 工程」。新建的 `.md` 是空白文本，`.mdk` 包含一个默认文稿。Markdown 的默认打开方式仍由系统和安装时的文件关联选项决定。

- **应用语言**。在「应用设置 → 应用语言」选择跟随系统、English 或简体中文，保存后重启应用。跟随系统时，不支持的系统语言使用英文。

- **统一控件**：下拉选项使用自绘蓝白样式，提供选中标记、分组、滚动和键盘选择，弹窗内也使用相同控件；字体建议支持选择与直接输入。左侧导航栏展开、收起时宽度平滑过渡，文字淡入淡出，工作区跟随调整；系统启用“减少动画”时关闭过渡。
- **双击打开方式**：每个外部打开的 `.md` / `.mdk` 使用独立窗口，各自保留文档、编辑状态、草稿和关闭保存流程。在“应用设置 → 双击文件时打开的视图”选择预览、源码或可视化，默认预览。适用于文件关联和启动时直接打开的 `.md` / `.mdk`，保存偏好后立即对下一次打开生效，重启后保留；新建工程仍进入源码。无法无损可视化的内容自动使用源码编辑。
- **单 Markdown 工程**：在新建工程中选择“单 Markdown 工程”，保存为普通 `.md` 文件；“打开工程”也支持直接打开 `.md`，包含文件关联和命令行启动。复用源码、可视化、预览、标题大纲、右键菜单及双栏同步；普通保存、自动保存、关闭保存和草稿恢复直接作用于此文件。不会创建 MDK 容器或 TOML 控制文件。
- **应用内打开与保存**。通过应用打开已有文档或在文稿目录、整体目录和双栏文件选择器切换 Markdown 时，默认进入预览。手动保存的结果显示在编辑区右上角的保存按钮内。
- **重命名 MDK 工程**。在编辑区右上角点击铅笔图标，可修改当前文件夹内的 `.mdk` 文件名。已打开的文稿和编辑组会继续留在当前窗口。
- **单文件功能边界**：工程模式、文稿层级编排、新建工程文件/目录、`contents.toml`、`settings.toml` 和工程设置保持可见并置灰。导出页提供 PDF，MDK 容器校验交付仅在 MDK 工程显示。切回 MDK 后恢复完整功能。图片/音视频/PDF 可拖入正文，归档至 `.md` 所在目录的 `resources/`；引用预览限定在该目录及子目录，拒绝路径逃逸和目录链接。
- **文稿目录**。由 `contents.toml` 的 `documents` 与 `nodes` 控制。可添加只有标题的分组，同一正文可以在多个目录位置出现。拖到行中央形成子层级，拖到行上下调整顺序。移动时保留节点 ID 和子树，应用支持最多 128 层。删除节点后，子节点提升一层，正文保留。
- **整体目录**。查看工程文件，打开 `mdk.toml`、`contents.toml`、`settings.toml`、`publication.toml` 及其他文本。二进制文件显示媒体预览或文件信息。
- **资源管理**。在「整体目录」右键点击 `resources` 下的任意文件夹，即可新建子文件夹、导入多个文件或导入保留结构的文件夹。重命名会更新可识别的 Markdown、字体和封面引用。标准分类目录及内置字体由 Mardikor 管理。
- **多选与提取**。开启「多选」后可勾选文稿、TOML、资源和目录。勾选目录会选中其子项，取消部分子项会显示半选。在已选行上右键可提取所选项，批量提取会在目标位置创建独立目录，并保留工程内部的相对路径。
- **源码**：Monaco 行号、折叠、查找替换、多光标、撤销重做和 TOML/JSON 诊断；从左侧文件树切换文件。Markdown 可切换可视化、预览或源码预览分栏。关键文件保存前校验。
- **文档查找**。点击编辑组的查找按钮，或按 Windows/Linux 的 `Ctrl+F`、macOS 的 `⌘F`，打开浮动查找框。所有视图均匹配 Markdown 源码，包括未保存的修改。正文标记所有命中，并用更醒目的颜色显示当前项。齿轮菜单可设置区分大小写，以及当前文档、当前文档及其子文档或全部文档的查找范围。按 `Enter` 或 `Shift+Enter` 循环跳转，也可以输入命中编号后按 `Enter`。跳转保留当前视图，左侧目录和标题大纲标记命中。对于链接地址等源码语法，正文视图会定位到对应元素。按 `Esc` 关闭。
- **标题大纲**：自动解析当前 Markdown 的 H1–H6 和 Setext 标题，按层级显示在左侧；点击可定位源码、可视化正文或预览。代码块中的示例标题不进入大纲。
- **双栏编辑**：使用工具栏“向右拆分编辑器”（`Ctrl+\`）或文件菜单“在旁侧打开”。每栏可独立选择文件以及源码、可视化、预览或设置；点击某栏后，左侧目录和标题大纲跟随该栏。两栏打开同一文件时共享内容，Monaco 源码共享撤销历史；滚动任意一栏，另一栏按阅读进度双向同步。拖动中间分隔条调整宽度，`Ctrl+Shift+1` / `Ctrl+Shift+2` 切换编辑组。保存、交付和草稿恢复覆盖两栏的全部更改。
- **键盘快捷键**。在可视化正文中，`Ctrl+1` 至 `Ctrl+6` 把当前段落设为对应级别的标题，`Ctrl+0` 将其恢复为正文。`Ctrl+B` 加粗，`Ctrl+I` 斜体，`Ctrl+E` 切换行内代码，`Ctrl+Alt+C` 切换代码块。进入“应用设置 → 配置快捷键”可查看和更改绑定，也可清除绑定或恢复默认值。
- **侧栏高度**：文稿/工程目录与标题大纲默认各占可用区域的一半，分别滚动。拖动横向分隔条调整高度，双击或按 Enter 恢复均分，也可用方向键调整。
- **可视化与预览**。格式工具栏独立于正文滚动。MDK 按工程的预览宽度和布局显示，连续布局可以浏览编排正文，文档布局可以按单篇或双页查看。独立 Markdown 使用随窗格宽度调整的预览。
- **Markdown 功能区**：按编辑、文本、段落、插入分组，支持 H1–H6、加粗/斜体/删除线/行内代码、引用、三类列表及层级、链接与图片属性、代码块及语言、分隔线和硬换行。GFM 表格支持行列增删和整列对齐；保持标准单段落单元格，不生成 HTML 换行或合并单元格。
- **右键菜单**：可视化正文提供撤销、剪切/复制/粘贴、纯文本粘贴、复制为 Markdown、全选及链接/图片/表格上下文操作。Monaco 保留原生菜单，并增加 Markdown 格式命令与语法模板；支持 `Shift+F10`，可视化链接使用 `Ctrl+K`。
- **源码语法**。MDK v2 预览和出版采用 CommonMark 与规范指定的 GFM 扩展。链接到标题时使用 v2 的 `#h-…` 锚点。原始 HTML、公式、脚注和容器语法在 v2 视图中保留为正文文本。独立 Markdown 继续支持原有的公式和容器渲染。
- **大纲与软件主题**。标题大纲默认跟随当前窗格，可在应用设置中关闭。软件主题支持浅色、深色、护眼和跟随系统，并应用于窗口和编辑器。工程可以为可视化编辑和预览单独设置文稿配色。
- **文稿分页**：长文稿的可视化编辑和预览共用分页，并连续滚动显示。可在编辑模式栏右侧输入页码跳转，双栏同步所在页与滚动进度。可视化模式会保留滚动前的编辑位置，点击其他页正文即可移动光标。编辑器会随光标加载相邻页，最多同时编辑三页，可在已加载的范围内跨页选择和撤销。在应用设置的「编辑与保存」可调整每页目标字符数（默认 8,000），也可关闭正文旁的分页标记。超出可视化编辑范围的文稿可以连续预览，并通过源码编辑。
- **拖放插入**：将本地白名单文件拖入 Markdown 源码或可视化正文，自动归档到 `resources/image`、`audio`、`video` 或 `other`，生成相对引用；重名自动递增。图片直接显示，音视频和 PDF 插为附件链接。白名单为 PNG、JPEG、GIF、WebP、BMP、AVIF、被动 SVG、MP3、WAV、OGG、FLAC、AAC、M4A、MP4、WebM、PDF，同时检查文件格式。一次最多 16 个文件、合计 64 MiB；不支持或格式伪造时整批拒绝并提示，正文和资源一起原子保存。
- **工程设置**。设置正文、预览和阅读的常用选项，或直接打开 `settings.toml` 编辑。对暂未实现的高级设置，校验报告会标记对应字段，普通保存保留工程中的值。
- **解包后查看目录**：在「工程设置 → MDK 交付」勾选「生成 Markdown 目录（contents.md）」并保存。保存工程或交付 MDK 时，Mardikor 会按 `contents.toml` 的顺序和层级更新包根目录的 `contents.md`。解包后，可用支持本地 Markdown 链接的应用打开它并跳转到正文。此选项默认关闭，关闭后保存会移除应用生成的副本；同名自建文件会保留。
- **阅读模式**。书籍和漫画工程可在「预览」旁进入「阅读」。书籍支持单页、双页和随阅读区宽度自动切换，双页每次翻过一个跨页。漫画按文稿单页或双页翻页。滚动模式可连续浏览当前文稿，用底部目录或前后文稿按钮切换章节。点击右下角悬浮按钮，可铺满可用宽度或限制单页宽度，并调整留白、页间距、字体、字号、行距、首行缩进、段落间距、对齐和侧栏显示。漫画还可调整图片适应和翻页方向。可保存、应用、更新或重命名最多 16 个本机预设。阅读设置独立于 MDK，背景随应用主题。
- **PDF / EPUB 导出**。在「校验与导出」创建、选择或预检出版预设。可在「工程设置 → 编辑出版预设」修改预设源码。三个 MDK 模式均可使用 PDF 和 EPUB 预设，独立 Markdown 支持 PDF。详见 [导出配置](./EXPORTING.md)。

普通保存允许继续编辑尚缺文件或资源的工程。「交付预检」显示基础内容、展示和出版等各校验范围。交付副本默认保留持久文件，并排除可重建的 `state/`。可在预检后选择携带状态或核对并剔除指定的附加文件。

超过应用设置中的目录同步阈值后，通过「更新目录」或保存提交目录变更。
