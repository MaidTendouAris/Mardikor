# Mardikor 0.3.1

**本版采用 MDK v2。** 旧版 MDK v1 工程请使用原有应用版本打开。0.3.1 支持直接打开独立 Markdown 文件。

## MDK v2

- 工程使用标准 ZIP。`mdk.toml` 保存用途和作品信息，`contents.toml` 分别登记正文和目录节点。支持分组、拖动层级及重复引用同一正文。
- 三种工程模式均可使用命名预设导出 PDF 或 EPUB。可在「校验与导出」新建预设，查看严格预检结果，再选择输出位置。
- 交付默认保留持久资料，排除可重建状态。可为单次交付调整携带范围。

## 编辑器与 CLI

- 切换文稿时保留工程侧栏和未变化的预览内容。预览查找显示命中计数，区分全部命中与当前项，并支持循环跳转。
- 只读工程显示对应的校验提示。书籍和漫画样例包含可用于验证出版的预设。
- CLI 支持 v2 工程的创建、编辑、校验、交付和解包。`rename` 与 `apply.writes` 可按正文 ID 或文档节点 ID 操作。

## 下载

- `Mardikor-Setup-0.3.1-x64.exe` 为 Windows x64 安装版。
- `Mardikor-Portable-0.3.1-x64.exe` 为 Windows x64 便携版。
- `mardikor-cli-0.3.1.tgz` 可在 Node.js 22.12 或更高版本下通过 `npm install -g ./mardikor-cli-0.3.1.tgz` 安装。

Windows 可执行文件未签名。校验值见 `CHECKSUMS.sha256`。
