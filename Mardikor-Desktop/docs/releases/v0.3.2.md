# Mardikor 0.3.2

## Markdown 与预览

- 在「工程」页使用「Markdown 转 MDK」，递归收录本地 Markdown 文稿、媒体和附件。转换会改写包内链接，跳过缺失引用并生成转换报告。报告排在文稿目录首位，转换完成后新工程自动打开。
- 编辑器中的「预览」只显示当前文稿，标题大纲随文稿切换。长文稿可分页，包内链接可以跳到其他文稿的指定标题。按阅读顺序浏览多篇文稿可使用「阅读」。

## Windows 安装

- 首次安装默认勾选 `.md` 关联，可在安装时取消。更新沿用已保存的选择。`.mdk` 自动关联。

## 下载

- `Mardikor-Setup-0.3.2-x64.exe` 为 Windows x64 安装版。
- `Mardikor-Portable-0.3.2-x64.exe` 为 Windows x64 便携版。
- `mardikor-cli-0.3.2.tgz` 可在 Node.js 22.12 或更高版本下通过 `npm install -g ./mardikor-cli-0.3.2.tgz` 安装。

Windows 可执行文件未签名。校验值见 `CHECKSUMS.sha256`。
