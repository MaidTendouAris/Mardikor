# Mardikor 0.3.4

- 在打开的 MDK 中添加、更改或移除访问口令。确认后随当前编辑一起保存，保留当前文稿和编辑组。
- 生成 MDKE 时可选自动、STORE、Zstandard 等级 3 或等级 9。命令行对应 `mdke-pack --compression`。
- 编辑器顶部的「校验与导出」直接操作当前工程。PDF / EPUB 出版和 MDK / MDKE 交付各有独立入口，点击「返回文稿」继续编辑。
- PDF 和 EPUB 导出页直接显示版式与作品信息。工程只在保存已修改的选项时生成或更新出版配置。
- 启动窗口在首次显示前恢复尺寸和最大化状态。
- 出版草稿在编辑器和导出面板切换时保留，顶栏保存会提交所有待保存的出版配置。交付范围变化后即时更新摘要，并提示重新预检。
- 校验结果可打开关联文件，尺寸错误显示在相关字段旁。改进窄窗布局、标签键盘导航、工程字体选择和应用设置保存入口。
