# Mardikor 0.3.5

- 重做独立音视频播放器。进度、播放、音量、倍速、循环、另存和全屏集中在窗口底部，音频和视频共用同一套主题化控件。
- 预览页内可直接播放本地音视频。播放器随预览栏宽度缩放，右键可在新窗口播放。进度和音量均使用自绘滑条，音量实时显示百分比，默认 30%。
- 在可视化编辑器拖入图片、视频、音频或其他文件时，指示线显示实际插入位置。插入栏支持搜索和引用包内资源。
- 导入资源时自动核对扩展名和文件签名。已识别的资源按类别存放，其余文件放入 `resources/other`。
- Windows 上的工程保存会短暂重试因读取占用而失败的文件替换。CLI 并发写入时，源工程在读取期间被替换也会返回修订冲突。

[查看 0.3.4 的工程保护、校验与导出改动](https://github.com/MaidTendouAris/Mardikor/blob/main/Mardikor-Desktop/docs/releases/v0.3.4.md)
