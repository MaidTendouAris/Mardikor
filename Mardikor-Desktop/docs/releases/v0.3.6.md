# Mardikor 0.3.6

- 文内和独立音视频播放器直接显示音量滑条和百分比。音频使用紧凑控制栏。视频播放时，控制栏和鼠标指针随鼠标活动一起显隐，右键菜单、倍速菜单和设置面板采用半透明深灰样式。
- 视频进度条支持悬停预览画面。音视频均支持倍速、循环、全屏、播放统计和音效调节。播放器获得焦点后可用方向键跳转或调节音量，长按左右键可临时以 2 倍速播放。视频还支持亮度、对比度和饱和度调节。
- 可视化编辑和预览统一表格样式。表格工具悬浮在正文底部，随光标自动展开或收起，也可手动切换。应用设置可选择是否允许表格横向滚动，并修复了设置页滚动时标题栏上方的缝隙。
- 编辑器可从上次关闭的位置继续。MDK 状态栏显示光标位置、当前文稿字符数和目录登记文稿的总字符数。修复旧工程的 `contents.toml` 和 `settings.toml` 误报。
- PDF 导出前可预览实际分页后的文件。预检使用当前纸张、边距和字体计算表格宽度，报告溢出的文稿和行号。
- 工程设置和导出页可搜索系统字体。导出页支持打包可分发的 OTF 或 TTF，预览遇到缺失字体时使用内置 Noto 字体。
- 支持在标题大纲中移动同级章节，正文和子标题随章节一起移动。可视化编辑新增可搜索的 Markdown 操作菜单、格式快捷键和表格单元格键盘导航。
