# Electron / React 迁移

## 范围

替换原有桌面载体、Rust 文件服务、Vue 页面和相关构建链。使用 Electron 主进程、沙箱 preload、React 渲染器与正式版 TypeScript 7。界面重新设计为蓝色创作工作区，纸张始终纯白。

`MDK Format Specification v1.md` 保持原样。继续使用两字节 ASCII 十六进制 mode + ZIP；首项 `mimetype` 为 STORE，固定 MIME；`contents.toml` 控制目录，`settings.toml` 与 `meta/` 可缺省。未知 mode 保留用途值并只读显示通用内容，附加约束标为未验证。contents 的未来 schema 阻止正常编辑；未来或无效 settings 临时回退并原样保留，严格交付前须处理。

## 行为

- PDF / EPUB 出版转换：default / 单 Markdown 为 PDF，book / comic 为 PDF + EPUB 3。配置使用 `extensions.mardikor.publication` 并复用原有排版字段；内置字体随配置写入 MDK。PDF 固定源码/依赖摘要、Electron/Chromium、平台与字体摘要，规范化元数据及源字符映射；EPUB 执行转换前严格预检和生成后的 XML/manifest/spine/引用自检。见 `EXPORTING.md`。

- 应用下拉使用基于 Radix 无样式组件的统一自绘控件，覆盖模式、工程/应用设置、双栏文件、功能区及原生对话框内的语法/图片选项。弹出层挂载到所属模态框，保持键盘、禁用项和分组；功能区关闭列表后恢复编辑器焦点。字体建议改为可自由输入的自绘组合框。导航以自身宽度驱动展开/收起动画，文本淡入淡出，减少动画偏好下禁用过渡。
- 外部双击/文件关联及启动参数打开的初始视图使用应用偏好，可选预览、源码、可视化，默认预览；先读取本机偏好再处理启动文件，避免启动时使用过期默认值。旧设置补齐预览默认值，非法值临时回退；新建工程和应用内打开保留原行为，恢复正文草稿仍进入源码。顶栏使用淡蓝底色和蓝灰文字，与下方纯白工作区区分。
- 独立 `.md` 工程复用同一编辑器和共享缓冲区，不转换为 MDK；通过独立文件后端保存 UTF-8 原文、检查磁盘摘要并原子替换，草稿仍存于应用数据目录。MDK 控制文件、层级和交付功能置灰；资源按相同白名单导入到文档旁的 resources，整批校验失败不写入，正文提交失败清理本次新增资源。
- 创建、打开、最近工程、中文文件名、条目增删改、六层目录与拖动排序。
- 超过偏好中的目录同步阈值时，显示待同步标记，通过“更新目录”或保存写入。
- 默认 Monaco Editor 源码编辑，使用官方编辑能力和语言组件；React Arborist 提供虚拟化文件树、键盘导航和真实拖动。
- “文稿目录”按 contents 的显式位置构建层级，支持拖入、整棵子树移动和菜单调整层级；“整体目录”展示真实文件结构并提供文件/目录管理。
- Tiptap 作为辅助 Markdown 可视化编辑；支持任务列表、容器预览、资源导入、字体、媒体预览及漫画资源跨页查看。
- 格式工具栏独立于正文滚动，左侧自动生成当前 Markdown 的标题大纲，支持源码、可视化和预览定位；通用模式按窗口宽度显示当前文稿，书籍/漫画保留排版预设。
- 左右编辑组独立选择文件和视图，目录跟随活动编辑组；同文件共享缓冲区，Monaco 共享文档模型和撤销历史。源码、可视化、预览和原有源码预览分栏都按阅读进度双向同步滚动。左右宽度及目录/大纲高度均可拖动调整，侧栏默认均分。多文件更改与目录/设置一次原子保存，恢复草稿覆盖两个编辑组。
- 本地白名单图片、音视频和 PDF 可直接拖入正文或源码，自动归档 resources 分类目录并插入相对图片/附件引用；正文和资源一次原子保存，不支持的批次拒绝且不修改工程。
- 工程设置覆盖规范全部字段，补齐书籍预览编号、目录深度和手动按标题拆分；细项及边界见 `MDK Feature Audit.md`。
- 可视化功能区覆盖 CommonMark 基础语法与 GFM 删除线、任务列表、表格；提供链接/图片属性、代码语言、列表层级、表格行列和整列对齐。正文右键菜单支持原生剪贴板、复制为 Markdown 及上下文操作；Monaco 原生菜单增加语法模板与格式命令。
- 包含容器、原始 HTML 和引用定义时，提示使用源码模式并禁止可视化改写，避免破坏原文。语法模板可直接转入源码；基础预览仍将所有原始 HTML 作为文本，包括 `<br>`。表格保持标准 GFM 结构，不支持依赖 HTML 的单元格换行或合并。
- 未修改文稿不会因为加载或切换界面而重新序列化；源码写入保留换行、注释和未知字段。
- 保存前校验本次修改的控制字段，正文、目录、设置使用一致快照并检查磁盘摘要冲突；先写临时文件、重新读取校验，再原子发布。单文件 64 MiB，压缩文件和解包总量上限 256 MiB，最多 10,000 个 ZIP 项。
- 普通保存允许缺失正文和资源的未完成工程，严格交付强制检查设置和全部已知引用；默认保留批注和未知 meta，剔除持久数据须确认本次范围，include_editor_state 控制已识别的可重建状态。
- 最近工程与偏好使用应用数据目录中的 `workspace.json`，独立于 MDK；没有 SQLite 或 Rust 工具链依赖。原实现的数据库初始化仅包含演示记录，无需迁移真实数据库数据。
- IPC 仅接受受信任主窗口的预定义命令、有效参数与用户选择 / 最近记录授权的路径。渲染器不能使用 Node.js，不能直接接触文件系统或原始 ipcRenderer。
- 打开 `.mdk` 文件关联请求会进入同一个应用实例。窗口关闭时提示未保存更改。

2026-11-03 修订规范已统一内容模型：book/comic 均为 default 的 Markdown 用途预设。书籍/漫画阅读预览按实际目录项展示完整文稿；漫画双页按条目配对，不按图片拆页。通用模式显示当前 Markdown，标题与目录在视图中按用户要求处理，不改写工程设置。完整行为见 `MDK Feature Audit.md`。

## 验证

`npm test` 验证规范容器、最小工程、可选设置、稳定 ID、中文命名、层级、原文与扩展数据保留、资源引用、失败保存、打包往返和本地偏好。

`npm run test:roundtrip` 使用实际生产扩展验证六级标题、文本格式、嵌套/任务列表、引用、链接、行内图片、表格对齐、转义和嵌套代码围栏的语义往返；同时验证源码专用语法保护。`npm run test:markdown-tools` 验证真实窗口中的功能区、右键菜单、原生剪贴板、链接校验、图片导入、表格与源码模板。

`npm run test:desktop` 在已构建应用中执行真实 Electron / React 流程并截屏。各平台包应在目标系统运行 `npm run dist` 验证；发布签名由发布环境提供。

`npm run test:markdown-file` 覆盖独立 Markdown 的真实窗口流程，包括新建、启动打开、功能置灰、源码/可视化/预览、拖图、双栏同步、MDK 切换、恢复、自动保存和冲突保护。Windows 增加 assisted NSIS 安装向导，`.mdk` 自动关联，`.md` 在安装时可选；便携版继续提供且不修改关联。

设置 `MARDIKOR_TEST_EXECUTABLE` 为打包后的可执行文件路径，可对实际打包产物运行同一功能回归（打包程序的隐藏窗口不截图，视觉检查使用开发程序截图）。测试还覆盖无效源码阻止保存并保留缓冲区、取消关闭、保存关闭失败保护与重启草稿恢复、目录阈值下的手动同步、自动保存，以及启动时直接打开 MDK 文件。

运行时依赖已通过 `npm audit --omit=dev` 检查。打包工具的间接开发依赖仍有中等级别的 audit 提示，发布工具升级时应继续跟踪。
