# 使用指南

- **统一控件**：下拉选项使用自绘蓝白样式，提供选中标记、分组、滚动和键盘选择，弹窗内也使用相同控件；字体建议支持选择与直接输入。左侧导航栏展开、收起时宽度平滑过渡，文字淡入淡出，工作区跟随调整；系统启用“减少动画”时关闭过渡。
- **双击打开方式**：每个外部打开的 `.md` / `.mdk` 使用独立窗口，各自保留文档、编辑状态、草稿和关闭保存流程。在“应用设置 → 双击文件时打开的视图”选择预览、源码或可视化，默认预览。适用于文件关联和启动时直接打开的 `.md` / `.mdk`，保存偏好后立即对下一次打开生效，重启后保留；新建工程仍进入源码。无法无损可视化的内容自动使用源码编辑。
- **单 Markdown 工程**：在新建工程中选择“单 Markdown 工程”，保存为普通 `.md` 文件；“打开工程”也支持直接打开 `.md`，包含文件关联和命令行启动。复用源码、可视化、预览、标题大纲、右键菜单及双栏同步；普通保存、自动保存、关闭保存和草稿恢复直接作用于此文件。不会创建 MDK 容器或 TOML 控制文件。
- **单文件功能边界**：工程模式、文稿层级编排、新建工程文件/目录、`contents.toml`、`settings.toml` 和工程设置保持可见并置灰。导出页提供 PDF，MDK 容器校验交付仅在 MDK 工程显示。切回 MDK 后恢复完整功能。图片/音视频/PDF 可拖入正文，归档至 `.md` 所在目录的 `resources/`；引用预览限定在该目录及子目录，拒绝路径逃逸和目录链接。
- **文稿目录**：由 `contents.toml` 控制。拖到行中央形成子层级，拖到行上下调整顺序；菜单可新建子文稿、调整层级、重命名和删除。整个子树一起移动，最多六层，ID 保持稳定。
- **整体目录**：查看真实工程文件树，新建/移动/重命名/删除文件和目录；直接打开 `contents.toml`、`settings.toml`、`meta/*.json` 等文本。二进制文件显示媒体预览或文件信息。
- **源码**：Monaco 行号、折叠、查找替换、多光标、撤销重做和 TOML/JSON 诊断；从左侧文件树切换文件。Markdown 可切换可视化、预览或源码预览分栏。关键文件保存前校验。
- **标题大纲**：自动解析当前 Markdown 的 H1–H6 和 Setext 标题，按层级显示在左侧；点击可定位源码、可视化正文或预览。代码块中的示例标题不进入大纲。
- **双栏编辑**：使用工具栏“向右拆分编辑器”（`Ctrl+\`）或文件菜单“在旁侧打开”。每栏可独立选择文件以及源码、可视化、预览或设置；点击某栏后，左侧目录和标题大纲跟随该栏。两栏打开同一文件时共享内容，Monaco 源码共享撤销历史；滚动任意一栏，另一栏按阅读进度双向同步。拖动中间分隔条调整宽度，`Ctrl+1` / `Ctrl+2` 切换编辑组。保存、交付和草稿恢复覆盖两栏的全部更改。
- **侧栏高度**：文稿/工程目录与标题大纲默认各占可用区域的一半，分别滚动。拖动横向分隔条调整高度，双击或按 Enter 恢复均分，也可用方向键调整。
- **可视化与预览**：格式工具栏独立于正文滚动。default（00）显示当前 Markdown，使用窗口宽度和纯白背景，不套用固定纸张、页边距或正文内自动目录；book/comic 保留模式排版。视图调整不改写工程设置。
- **Markdown 功能区**：按编辑、文本、段落、插入分组，支持 H1–H6、加粗/斜体/删除线/行内代码、引用、三类列表及层级、链接与图片属性、代码块及语言、分隔线和硬换行。GFM 表格支持行列增删和整列对齐；保持标准单段落单元格，不生成 HTML 换行或合并单元格。
- **右键菜单**：可视化正文提供撤销、剪切/复制/粘贴、纯文本粘贴、复制为 Markdown、全选及链接/图片/表格上下文操作。Monaco 保留原生菜单，并增加 Markdown 格式命令与语法模板；支持 `Shift+F10`，可视化链接使用 `Ctrl+K`。
- **源码语法入口**：提供自动链接、Setext 标题、缩进式代码块、转义、引用式链接/图片及原始 HTML 模板。引用定义、原始 HTML 和 MDK 容器使用源码编辑，避免可视化改写丢失信息；原始 HTML 在基础预览中显示为文本。
- **拖放插入**：将本地白名单文件拖入 Markdown 源码或可视化正文，自动归档到 `resources/image`、`audio`、`video` 或 `other`，生成相对引用；重名自动递增。图片直接显示，音视频和 PDF 插为附件链接。白名单为 PNG、JPEG、GIF、WebP、BMP、AVIF、被动 SVG、MP3、WAV、OGG、FLAC、AAC、M4A、MP4、WebM、PDF，同时检查文件格式。一次最多 16 个文件、合计 64 MiB；不支持或格式伪造时整批拒绝并提示，正文和资源一起原子保存。
- **工程设置**：控制外观、布局、预览、交付和模式字段；书籍模式可启用手动按标题拆分，漫画模式按完整 Markdown 文稿进行单页、双页及左右阅读编排。
- **PDF / EPUB 导出**：default 与单 Markdown 支持 PDF；book / comic 支持 PDF 和 EPUB 3，原有 MDK 容器交付保留。提供作品信息、封面、字体、纸张/边距、颜色、分页、目录、页眉页脚、页码范围、缩放、灰度、标签/书签及 EPUB 布局/阅读顺序选项。新增配置位于 `settings.toml` 的 `[extensions.mardikor.publication]`，不改写 v1 的 `export.default_target = "mdk"`。详见 [导出配置与可复现性](./EXPORTING.md)。

按照 2026-11-03 修订规范，普通保存允许未完成工程；严格交付检查所有已知依赖。默认保留批注和未知 meta，剔除持久数据需确认。设置按字段回退，草稿恢复与磁盘冲突保护独立于 MDK。

目录树操作与 TOML 源码双向更新。超过应用设置中的阈值后，目录变更通过“更新目录”或保存提交。完整核对和实现边界见 [MDK 功能核对](./MDK%20Feature%20Audit.md)。
