# Mardikor 0.1.0

首个 Windows x64 公开版本，采用 GPLv3（GPL-3.0-only）协议。

- Electron + TypeScript 7 + React，支持 MDK 工程和普通 Markdown 文件。
- Monaco 源码、可视化、预览、双栏编辑与双向滚动同步。
- 文稿层级与目录拖动、工程文件管理、标题大纲及本地资源拖入。
- MDK 规范校验、PDF 出版及 book/comic 的 EPUB 转换。
- 双击多个文件打开独立窗口，独立草稿与保存冲突保护。
- 默认每 24 小时检查一次 GitHub Releases，可在应用设置中关闭。仅提示新版本；下载和安装分别由用户手动发起，退出时不会自动安装。
- 安装更新前处理所有窗口的未保存内容，取消或保存失败均保留当前文档。

Windows 安装版：`Mardikor-Setup-0.1.0-x64.exe`。自动关联 `.mdk`，安装时可选关联 `.md`。

Windows 便携版：`Mardikor-Portable-0.1.0-x64.exe`。便携版通过发布页下载新版本，不覆盖自身或转成安装版。

`latest.yml` 与 `.blockmap` 供安装版更新使用；`CHECKSUMS.sha256` 提供发布文件校验值。对应源码可通过本发布的 Source code 下载。
