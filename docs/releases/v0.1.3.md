# Mardikor 0.1.3

- 设置页加入版本号、内置 GPLv3 许可证、GitHub 仓库及 Issues 反馈入口。
- 切换 MDK 文稿时沿用编辑视图。缩放适用于源码编辑器，内置查找和菜单支持中文。
- 修复长文档预览卡顿和窄栏裁切。支持粘贴图片，单 Markdown 可打开 GBK／GB18030 文件，修改后保存为 UTF-8。
- 预览与出版导出支持脚注，单文件支持提示块。统一书籍正文、目录和书签编号。
- 新 PDF 配置默认 A4，支持使用内置字体显示常见表情。EPUB 导出仅嵌入所用字形，Windows 应用包体积缩小。
- 打包解包目录时提前检查控制文件，校验与导出页区分容器校验和出版预检。

Windows x64 提供安装包和便携版。已安装的版本可从设置页手动下载并安装更新。固定旧 PDF 渲染引擎的工程，使用新版导出前需重新保存导出配置。
