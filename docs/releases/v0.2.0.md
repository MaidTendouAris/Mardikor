# Mardikor 0.2.0

- 新增 `mardikor` 命令，可直接创建、读取、编辑和校验 MDK 工程，支持文稿层级调整、资源导入和批量修改。
- 脚本和 AI 可以按文稿 ID 定位章节，使用 JSON 结果和标准输入提交修改。桌面端与 CLI 共用写入锁，修改时校验工程修订号。
- Windows 安装版按安装范围注册 PATH，安装完成后重新打开终端即可运行 `mardikor --help`。Windows 便携版保留单 EXE 图形界面。
- Linux 服务器可用 Node.js 22.12 或更新版本，运行 `npm install -g ./mardikor-cli-0.2.0.tgz` 安装全局命令。
- 命令行指南可在源码的 `docs/CLI.md` 和应用设置页离线查看。

已安装的 Windows 版本可从设置页手动下载并安装更新。固定旧 PDF 渲染引擎的工程，使用新版导出前需重新保存导出配置。
