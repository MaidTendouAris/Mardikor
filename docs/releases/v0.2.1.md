# Mardikor 0.2.1

- 长文档采用后台分页预览和虚拟大纲。超过排版上限的文稿可在源码模式编辑和保存，超长单行的输入延迟也已改善。
- 标题大纲默认跟随当前编辑或预览窗格，可在应用设置中关闭。文稿预览支持数学公式，文稿配色可选浅色、深色、护眼或跟随系统。
- 桌面端检测到 CLI 或其他程序修改文件时会刷新工程。有本地草稿时可对比磁盘版本、另存草稿副本或重新加载。
- CLI 支持 GB18030 输入、BOM 处理、逐命令帮助、修订监听和遗留锁清理。
- PDF 目录增加页码，导出可一并保存配置。EPUB 支持嵌入表情字形，原始 HTML 按文本显示。仅导出 EPUB 时，默认字体按需嵌入导出文件。

已安装的 Windows 版本可从应用设置下载并安装更新。Linux 可用 Node.js 22.12 或更新版本运行 `npm install -g ./mardikor-cli-0.2.1.tgz` 安装 CLI。固定旧 PDF 渲染引擎的工程，使用新版导出前需重新保存导出配置。
