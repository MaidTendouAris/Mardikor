# Mardikor 0.2.2

- 可视化编辑和预览共享分页。翻页控件固定在工具栏右侧，支持输入页码跳转，应用设置可调整每页长度。超大文稿可使用源码和分页预览。
- PDF 和 EPUB 导出显示处理进度，导出计算在后台执行。
- TOML、JSON 等文本文件仅启用源码编辑，图片等媒体文件仅启用预览。编辑区顶栏可在资源管理器中定位当前文件或所属的 MDK 工程包。
- 软件主题应用于整个窗口和编辑区。深色主题采用 VS Code 风格的炭灰配色，也支持浅色、护眼和跟随系统。
- 从应用内手动安装更新时沿用原安装设置，更新完成后自动重启 Mardikor。

Windows 用户可下载安装包或便携版。Linux 用户可使用 Node.js 22.12 或更新版本，通过 `npm install -g ./mardikor-cli-0.2.2.tgz` 安装 CLI。
