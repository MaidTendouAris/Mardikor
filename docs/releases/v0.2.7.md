# Mardikor 0.2.7

## 编辑与阅读

- 在应用内打开 Markdown 或切换文稿时默认进入预览。标题大纲集中在侧栏，正文预览直接显示内容。
- 手动保存的进度和结果显示在保存按钮内。可视化编辑的自动保存和快捷键保存保留光标位置。
- 支持自定义编辑快捷键、浅色和深色主题，以及跟随系统、英文和简体中文界面。
- 大文稿支持连续滚动、按页跳转和可关闭的分页标记。MDK 的可视化编辑保护按当前 Markdown 文稿判断。

## MDK 工程与 CLI

- 可在编辑区右上角重命名 MDK 工程文件，并在原窗口继续编辑。
- 整体目录支持多选和右键批量提取。选中文件夹时会选中子项。资源目录支持嵌套文件夹和批量导入。
- CLI 支持批量新增文稿、静默输出和指定文稿标题。

## 更新

- 设置页可以渲染 GitHub 发布说明中的标题、列表、代码与链接。

Windows 用户可下载安装包或便携版。Linux 用户可使用 Node.js 22.12 或更新版本，通过 `npm install -g ./mardikor-cli-0.2.7.tgz` 安装 CLI。
